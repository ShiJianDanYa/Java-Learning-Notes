## 初识 python
### 作者
Python 是荷兰计算机科学家吉多·范罗苏姆（Guido van Rossum，龟叔）在 1991 发布的一门语法简单、容易上手的编程语言。
![[01_创始人图片_2026-07-23_15-09-59.png]]

### 编程语言
语言 是人类进行沟通交流的主要表达方式。
编程语言：是人类与计算机之间进行信息交流的一种特殊的语言。

### python 应用范围
1. Python 课程/计算机二级/ACM 竞赛等
2. 办公自动化(Excel/Word/PDF...)
3. 网络爬虫程序/数据采集程序开发
4. Web 应用/网站服务端程序开发
5. 数据分析/可视化图表制作
6. 大数据开发/分布式计算开发
7. 自动化测试/测试开发/运维开发
8. AI大模型开发/机器学习/深度...(最火爆)

## python 是什么
Python 是一门语法简单、容易上手且应用非常广泛
的编程语言。
