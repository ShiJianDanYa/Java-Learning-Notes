Web：全球域网，也称为万维网（www WorldWide Web），能够通过浏览器访问的网站。
有各种各样的网站如图所示
![[01_web网站_2026-05-15_19-50-28.png]]

web网站的三个组成及其功能
1. 前端程序 界面展示
2. 服务端程序 业务逻辑处理
3. 数据库 数据的存储和管理

web 网站的访问流程
![[02_web网站访问流程_2026-05-15_19-59-02.png]]
1. 打开浏览器在界面输入网址
2. 访问服务器中部署的前端程序，但是前端程序作用，是将数据以好看的样子呈现出来，但是数据并不是再前端中写死的
3. 前端程序发送请求，请求服务端程序，服务端程序访问数据库
4. 数据库拿到数据 返回给数据库 数据库给 服务端 前端 服务器 浏览器 以此类推
