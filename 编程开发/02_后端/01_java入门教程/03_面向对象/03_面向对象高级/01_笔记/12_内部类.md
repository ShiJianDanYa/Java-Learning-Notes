# 知识目录

# 1— 引入问题
如果让我们写一个 javaBean 类描述汽车
属性：汽车的品牌，车龄，颜色，发动机的品牌，使用年限
```java
public class Car {
	//车的属性
	String carName;
	int carAge;
	int carColor;
	//发动机的属性
	String engineName;
	int engineAge;
	}
```
但是其实发动机品牌和使用年限其实并不是汽车的属性
将发动机独立出来也不太符合逻辑,因为发动机是车的一部分
不如定义在汽车类的里面
```java
public class Car {//外部类
	String carName;
	int carAge;
	int carColor;
	class Engine {//内部类
		String engineName;
		int engineAge;
	}
}
```
那我们应该什么时候使用内部类呢?
两点
1. `内部类表示的事物是外部类的一部分`
2. `内部类单独出现没有任何意义`

# 2— 核心内容 内部类
## 内部类定义
内部类：在一个类的里面，再定义一个类
## 格式
```java
public class Outer { //外部类
	public class Inner { //内部类
	
	}
}
```

## 内部类分类
### 成员内部类
写在成员位置的，属于外部类的成员。
#### 成员内部类书写时注意事项
* 写在成员位置的，属于外部类的成员
* 成员内部类可以被一些修饰符所修饰，比如：private，默认，protected，public，static 等
* 在成员内部类里面，JDK16之前不能定义静态变量，JDK16开始才可以定义静态变量
#### 成员内部类格式
```java
//成员内部类
public class Car { //外部类
	String carName;
	int carAge;
	int carColor;
	class Engine { //成员内部类
		String engineName;
		int engineAge;
```

#### 成员内部类如何获取外部类的成员变量
其实这里也是就近原则
代码
```java
public class Outer {  
    private int a = 10;  
  
    class Inner{  
       private int a = 20;  
  
       public void show(){  
          int a = 30;  
          System.out.println(a);  //30  
          System.out.println(this.a);  //20  
          System.out.println(Outer.this.a);  //30  
       }  
    }  
}
```
测试类代码
```java
public class Test {  
    public static void main(String[] args){  
       Outer.Inner li = new Outer().new Inner();  
       li.show();  
    }  
}
```
运行结果
```text
30
20
10

进程已结束，退出代码为 0
```
Outer.this.a 为什么可以调用外部类的成员变量

### 静态内内部类
`静态内部类是一种特殊的成员内部类`
#### 书写静态内部类注意事项
* 静态内部类只能访问外部类中的静态变量和静态方法
* 如果在静态内部类中，想要访问外部类非静态的内容，需要创建外部类的对象
```java
public class Car { //外部类
	String carName;
	int carAge;
	int carColor;
	static class Engine { //静态内部类
		String engineName;
		int engineAge;
	}
}
```
如何调用非静态的变量或方法
不能直接调用

### 匿名内部类
就是一个没有名字的内部类,可以写在成员位置，也可以写在局部位置
作用：在继承一个类或者实现一个接口的时候少写一个件，也是 lambda 的前置知识点
#### 匿名内部类格式
```java
new 类名或者接口名() {
	重写方法；
};
```
🌰
```java
new Inter() {
	public void show(){...};
}
```
如果一个方法的参数是接口
应该怎么做
如图
![[01_匿名内部是类_2026-05-29_11-38-26.png]]
传统方法分三步
1.新建 java 文件，在文件当中新建 Student 类（实现，重写方法） 
2.创建对象
3.通过给方法对象调用方法
![[02_匿名内部类_2026-05-29_11-42-06.png]]
但是就此方法来说
Student 类我只要用到一次，那么这个 java 文件单独新建有点浪费
是否可以不新建这个 java 文件，只要里面的代码呢？
可以用匿名内部类
`如果实现类只要使用一次，就可以用匿名内部类简化代码`
格式一
![[03_匿名内部类_2026-05-29_11-51-08.png]]
格式二
```java
//第二种方式  
Swim s1 = new Swim() {  
    @Override  
    public void swim() {  
       System.out.println("学生在蓝海游泳");  
    }  
};  
goSwimming(s1);
```

匿名内部类等价于
匿名内部类的定义格式 = 没有名字的 java 类 + 继承/实现 + 重写方法 + 创建对象  
最终格式可以理解为：是一个没有名字的 java 类的对象

我们来一步步拆解
没有名字的 java 类：大括号{...}  
Swim：就是这个没有名字的 java 类实现了 swim 接口  
![[04_匿名内部类_2026-05-29_11-59-45.png]]
重写方法：我们要在大括号当中重写 swim 所有的抽象方法  
创建对象：new 关键字作用的是后面这个合格没有名字的 java 类，创建了他的对象  ![[05_匿名内部类_2026-05-29_12-02-24.png]]
整体：创建了一个 Swim 实现类的对象，只不过这个类没有名字而已

而我们以前的解法
Swim ss = new Student();
是一种多态的体现
同样
```java
Swim s1 = new Swim() {  
    @Override  
    public void swim() {  
       System.out.println("学生在蓝海游泳");  
    }  
};
```
也是一种多态
由此可以推论 ,接口是一种特殊的父类
