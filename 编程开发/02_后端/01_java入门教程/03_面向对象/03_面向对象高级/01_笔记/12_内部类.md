# 知识目录

# 1— 引入问题
如果让我们写一个 javaBean 类描述汽车
属性：汽车的品牌，车龄，颜色，发动机的品牌，使用年限
```java
public class Car {
	//车的属性
	String carName;
	int carAge;
	int carColor;
	//发动机的属性
	String engineName;
	int engineAge;
	}
```
但是其实发动机品牌和使用年限其实并不是汽车的属性
将发动机独立出来也不太符合逻辑,因为发动机是车的一部分
不如定义在汽车类的里面
```java
public class Car {//外部类
	String carName;
	int carAge;
	int carColor;
	class Engine {//内部类
		String engineName;
		int engineAge;
	}
}
```
那我们应该什么时候使用内部类呢?
两点
1. `内部类表示的事物是外部类的一部分`
2. `内部类单独出现没有任何意义`

# 2— 核心内容 内部类
## 内部类定义
内部类：在一个类的里面，再定义一个类
## 格式
```java
public class Outer { //外部类
	public class Inner { //内部类
	
	}
}
```

## 内部类分类
### 成员内部类
* 写在成员位置的，属于外部类的成员
* 成员内部类可以被一些修饰符所修饰，比如：private，默认，protected，public，static 等
* 在成员内部类里面，JDK16之前不能定义静态变量，JDK16开始才可以定义静态变量

```java
//成员内部类
public class Car { //外部类
	String carName;
	int carAge;
	int carColor;
	class Engine { //成员内部类
		String engineName;
		int engineAge;
```

被 privat 修饰的成员内部类 ,是不可以直接在外面测试类中创建成员内部类对象的
为什么 私有修饰的 成员变量在外面不可以直接访问
什么都不写 就是空着 只能在统一个包中创建成员内部类的对象
protected 其他包下子类可以创建成员内部类的对象
public 所有对象都可以创建成员内部类的对象
