### 1.1— 什么是继承
面向对象的三大特征之一,
继承是类与类之间的一种父子关系,
java中提供关键字 `extends`,用于建立类与类之间的继承关系
![[04_继承_2026-05-21_10-23-27.png]]
继承的作用: 将多个子类中的重复代码抽取到父类,子类可以直接使用

### 1.2— 继承好处
* 可以把多个子类中重复的代码抽取到父类中了,提高代码复用性
* 子类可以在父类的基础上,增加其他的功能,使子类更加强大
![[05_继承_2026-05-21_10-26-33.png]]
### 1.3— 继承特点
java只支持单继承，不支持多继承，但支持多层继承
单继承：一个子类只能继承一个父类
不能多继承：子类不能同时继承多个父类
为什么不能多继承 如图所示 多个父类若方法相同，子类调用相同方法时，该如何判定使用的方法，是那个父类
![[01_继承_2026-05-21_14-30-34.png]]
多层继承：可以嵌套 爷爷被爸爸继承 ，而爸爸被儿子继承
![[02_继承_2026-05-21_14-31-56.png]]
细节一
直接父类 中间没有间隔 爷爷和爸爸 爸爸和儿子
间接父类 中间有间隔 儿子和爷爷（存在爸爸作为中介结点）
![[03_继承_2026-05-21_14-32-48.png]]
再加一个也一样
![[04_继承_2026-05-21_14-33-31.png]]
细节二 最终父类
存在一个万类之父 最顶级的父类Object，每一个类都直接或间接的继承于Object
在我们编写时除了我们自己设计的父类方法被继承,还有 Object 的方法被继承

### 1.4— 继承中的成员特点
#### 1.4.1— 成员变量
书写规则：把多个子类中的相同的属性抽取到父类中
![[01_继承中成员变量的特点_2026-05-21_14-43-42.png]]

但是在 `调用时`，遵循 `就近原则`
继承 就近
先在
1. 局部位置找
2. 本类成员位置找
3. 父类成员位置找

逐级往上，
![[02_就近原则完整版_2026-05-21_14-45-50.png]]
那我们想要分别用本类和父类呢？
本类

父类
![[04_父类就近_2026-05-21_14-49-05.png]]

代码演示
```java
public class Test {  
    public static void main(String[] args) {  
       Zi z = new Zi();  
       z.zishow();  
    }  
}  
  
class Fu {  
    String name = "Fu";  
}  
  
class Zi extends Fu {  
    String name = "zi";  
  
    public void zishow() {  
       String name = "zishow";  
       System.out.println(name); // zishow  
       System.out.println(this.name);// Zi  
       System.out.println(super.name); // Fu  
    }  
}
```
结果
```test

zi
Fu
```

#### 1.4.3— 构造方法
* 父类中的构造方法不会被子类继承,只能通过super关键字调用
![[01_继承中的构造方法_2026-05-22_06-39-42.png]]
那子类该如何调用父类的构造方法，用super关键字
![[02_继承中的构造方法_2026-05-22_06-41-00.png]]
为什么要这样，你想啊这两个属性作为共性，被抽取到父类中了，按理说属性在那个类里，就在那个类里赋值，通过super，就可以实现 `创建对象同时给成员变量赋值`
![[03_继承中的构造方法_2026-05-22_06-44-48.png]]
* 需要注意的是 如果子类的构造方法不写super，jvm也会加一个默认的super（），先访问父类的无参构造
题目要求
```text
学生:  
属性：姓名、年龄、年级  
  
老师:  
属性：姓名、年龄、学科
```

代码演示
学校人员
```java
public class Person {  
    String name;  
    int age;  
  
    public Person() {  
        System.out.println("父类的无参构造执行了");  
    }  
  
    public Person(int age, String name) {  
        System.out.println("父类的带参构造执行了");  
        this.age = age;  
        this.name = name;  
    }  
}
```

老师
```java
public class Teacher extends Person {  
    String subject;  
    //构造方法  
    //1. 无参构造  
    public Teacher()  
    {  
        System.out.println("子类Teacher的无参构造方法执行了");  
    }  
    //2. 有参构造  
    public Teacher(int age, String name, String subject){  
        this.age = age;  
        this.name = name;  
        this.subject = subject;  
        System.out.println("子类Teacher的有参构造方法执行了");  
    }  
}
```
学生
```java
public class Student extends Person {  
    String className;  
    //构造方法  
    //1. 空参构造  
    public Student(){  
        System.out.println("子类Student的无参构造方法执行了");  
    }  
    //2. 带参构造  （父+子）  
    //父类中的属性：通过super（参数）的形式传递给父类的构造方法赋值  
    //子类中的属性：自己赋值  
    public Student(int age, String name, String className){  
        this.className = className;  
        System.out.println("子类Student的有参构造方法执行了");  
        super(age, name);  
    }  
}
```

# 3— 注意事项
## 1— 继承体系中构造方法
1. 子类构造方法第一行，有一个默认的super（），如果我们没有书写，JVM也会自动加上
2. 如果想要访问父类的带参构造，super（参数）必须手动写上，不能省略
3. 在创建对象的时候，先执行父类的构造方法，再执行子类的构造方法
