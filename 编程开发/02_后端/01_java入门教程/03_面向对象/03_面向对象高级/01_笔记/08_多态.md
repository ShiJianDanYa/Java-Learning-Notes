## 多态是什么
是事物的多种形态
## 多态的表现形式
```java
//多态
父类类型 对象名称 = 子类对象；
```
## 多态的前提
* 有继承/实现关系 `必须的`
* 有父类引用指向字类对象 `必须的` ![[05_多态_2026-05-27_07-44-07.png]] 字类对象是 Zi();
* 有方法的重写 `可选的`
  为了实现子类的好处 2 
  可以根据对象调用其重写父类的方法
## 多态的好处
1. 方法的形参只要写父类,方法就可以接受它的所有子类对象
2. 在 register 里面 用对象调方法 只要字类重写了 show 方法,多态就可以根据传递的对象，调用不同类里的 show 方法(`根据传递不同的对象，调用子类不同的方法`)
![[04_多态_2026-05-27_07-35-03.png]]

## 多态弊端
弊端：多态下不能使用子类的独有功能
那么该如何解决呢?
那就是类型转换
### 类型⇄

`自动类型转换（从子到父）：` 子类对象赋值给父类类型的变量
`强制类型转换（从父到子）: `子类 对象变量 =(子类)父类类型的变量

格式
```java
Person p = new Student();
Student s = (Student)p;
```

`作用：` 可以解决多态的弊端，可以实现调用子类独有的功能
只能在 `直接父类` 中转换
代码演示
继承结构如下
Ye → Fu  → zi
Ye 类代码
```java
public class Ye {  
}
```

![[07_多态_2026-05-27_12-53-04.png]]
编译不报错,但是运行会报错
![[08_多态_2026-05-27_12-53-50.png]]
如何避免这种问题呢
先判断
代码演示
```java
//注意点：  
//继承关系
//爷爷-->爸爸-->儿子  
//创建了爸爸的对象，赋值给了爷爷类型  
//在进行强制类型转换的时候，只能转到爸爸类型，不能转成儿子类型  
Ye y = new Fu();  
//instanceof关键字  
// 语法：对象 instanceof 类名  
// 判断 对象 是否为 类名 的 父类类型  
if(y instanceof Fu){  
    Fu ff = (Fu)y; 
    //调用方法 
    ff.Fushow();  
    ff.show();  
}else{  
    System.out.println("y不是Zi类型");  
}
```

## Lombok 
Lombok 可以实现为类自动添加 getter setter 方法 无参数构造器，toString 方法等。
 @Data 注解可以自动生成 getter setter 方法 无参构造器 toString 方法等
直接写回报错
步骤书写后用 ait 和回车键
点击将 Lombok 添加到类路径中
![[09_Lombok_2026-06-19_22-22-35.png]]
弹出界面点击确定即可
![[10_Lombok_2026-06-19_22-23-28.png]]

演示代码
```java
@Data   //@Data注解可以自动生成getter setter方法 无参构造器 toString方法等  
@AllArgsConstructor //有参构造器 有了有参的无参自动取消  
@NoArgsConstructor //无参构造器 所以又需要手动添加无参构造器
```
