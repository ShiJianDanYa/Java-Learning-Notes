# 2— 核心内容
## 新特性
* `JDK 7 及以前：`
  接口中只能定义抽象方法
* `JDK 8 新特性:`
  为了接口升级时向下兼容，接口中可以定义有方法体的方法（默认、静态）
* `JDK 9 新特性：`
  为了抽取重复代码，接口中可以定义私有方法(私有普通方法，私有静态方法）

## JDK 8 以后接口中新增的方法
### 默认方法
允许在接口中定义默认方法，需要使用关键字 `default` 修饰
<font color="#00b0f0">作用：为了接口升级时，代码不报错</font>
#### 定义格式：
格式
```java
//格式
public default 返回值类型 方法名(参数列表){}
```
范例
```java
//范例
public default void show() {}
```
#### 注意事项：
* 默认方法不是抽象方法，所以不强制被重写。但是如果被重写，重写的时候去掉 default 关键字 
* public 可以省略，default 不能省略
* 如果实现了多个接口，多个接口中存在相同名字的默认方法，子类就必须对该方法进行重写

### 静态方法
允许在接口中定义定义静态方法，需要用`static`修饰
#### 定义格式：
格式:
```java
//格式
public static 返回值类型 方法名(参数列表){}
```
范例：
```java
//范列
public static void show() {}
```
#### 注意事项：
1. 静态方法只能通过接口名调用，不能通过实现类名或者对象名调用 
2. public 可以省略，static 不能省略

注意事项 1
![[01_静态方法注意事项1_2026-05-28_14-48-13.png]]
但是如果是继承,是可以通过对象调用父类的静态方法
![[02_继承静态_2026-05-28_15-15-56.png]]
为什么?
用对象去调用静态方法虽然不推荐
但是在语法上是允许的
如果调用首先会去本类中看是否存在此方法
没有会去看整个继承链
但是只会看继承类而不会去看接口
## JDK 9 私有方法
### 私有方法
在接口中方法体中重复的代码可以抽取出来
![[01_私有方法_2026-05-28_15-18-04.png]]
然后在需要的时候直接调用即可
![[02_私有方法_2026-05-28_15-20-41.png]]
这个抽取出的方法是给本接口中其他方法服务的,但是其他类也可以调用,怎么办,设为私有,只对本类开放

### 为什么
为了抽取默认方法和静态方法中重复代码而出现的
### 格式 
#### 格式一 default
格式
```java
//格式
private 返回值类型 方法名(参数列表） {}
```
范例
```java
//范例
private void show() {}
```
#### 格式二 为静态方法服务
格式
```java
//格式
private static 返回值类型 方法名(参数列表） {}
```
范例
```java
//范例
private static void method() {}
```
