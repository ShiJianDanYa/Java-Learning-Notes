# 1— 需要解决问题
一个方法中的参数过多，调用就会特别麻烦
# 2— 本质 意义 解决方法
## 1— 面向对象
对象:将相关的 `数据` 和 `方法` 组织为 `一个整体` 来看待
面向对象：利用对象进行软件开发
## 2— 类和对象
类：是描述（`限定`）一类事物
对象：记录单独个体的所有信息

对于限定
所谓对象就是把零散的数据看作一个又一个的整体
但是对于里面的变量不加以限制,就会造成要使用对象时
如果 时间过长 造成遗忘 要使用对象 那就必须要去看 对象代码 
所以 需要限定 `同一类事物的属性必须是一致的`

我的理解就是
类：给对象一个统一标准，避免你定义的对象缺胳膊少腿
(注意类 是只定义 赋值 类是用来描述,某一类事物,比如体重,你如果赋值为小 10 kg
所有小狗体重都是 10 kg 可能吗?不符合真实情况)
以狗为列子演示

对象：统一标准下的个体

类就是你所拥有的键盘
对象就是具体的键盘 塑料的 铝的 65 配列的 75 配列的 87 配列的等......

对象格式
```java
类名 对象名 = new 类名();
```

例子
Dog d = new Dog( );
new：创建一个大空间
Dog: 管理狗狗的信息
d: 大空间的名字
