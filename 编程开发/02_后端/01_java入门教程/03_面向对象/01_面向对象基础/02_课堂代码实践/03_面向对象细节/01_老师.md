# 📝 
## 📌 题目要求
> 
> **示例**：
> 面向对象思想表示老师  
> 属性：姓名、年龄  
> 行为：授课、吃饭、睡觉
> 输出：
> 姓名:张三-年龄:18
> 老师授课
> 老师吃饭
> 老师睡觉

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：创建老师类
2. 第二步：添加属性 姓名 年龄
3. 第三步：添加行为 授课 吃饭 睡觉 

## 💻 核心代码

```java
// 老师类
public class teacher {  
    /*  
    面向对象思想
    表示老师    
    属性：姓名、年龄    
    行为：授课、吃饭、睡觉    
    */    
    //属性    
    String name;  
    //年龄  
    int age;  
    //行为 能干什么 方法的形式进行体现(不加static)  
    //授课    
    public void teach(){  
        System.out.println("老师授课");  
    }  
    //吃饭  
    public void eat(){  
        System.out.println("老师吃饭");  
    }  
    //睡觉  
    public void sleep(){  
        System.out.println("老师睡觉");  
    }  
}
```

```java
//测试类
public class Test {  
    public static void main(String[] args){  
        //创建对象  
        teacher t1 = new teacher();  
        //附加属性  
        t1.name = "张三";  
        t1.age = 18;  
        //打印信息  
        System.out.println("姓名:"+t1.name+"-年龄:"+t1.age);  
        //老师的行为  
        t1.teach();  
        t1.eat();  
        t1.sleep();  
    }  
}
```
