# 📝 字符乘积
## 📌 题目要求
> 键盘输入两个字符串表示的非负整数，求它们的乘积。注意：需要考虑键盘录入的数据过大，超出int取值范围的
> **示例**：
> 输入：
> 请输入第一个非负整数字符串: 999
> 请输入第二个非负整数字符串: 999
> 输出：它们的乘积为: 998001

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：先接收用户输入的两个字符串
2. 第二步：排除特殊情况 有一个是 0 那结果就是 0
3. 第三步：定义两个变量 m n 存储字符串长度，定义一个整形数组长度为 m+n
4. 第四步：从右向左遍历两个字符串，从右向左遍历两个字符串
	1. 先循环遍历字符 1 截取字符变为整形 变量 n 1,在循环遍历字符 2 也变为整形变量那 n 2
	2. 变量 num 存储乘积 n 1* n 2  +当前位数（res[ i + j + 1 ]）
	3. 保留位数 个位数  结果%10  位置 i + j + 1，结果/ 10 十位数  位置 i + j
	4. 结果数组转换为字符串
		1. 判断最高位是否等于 0 等于 0 舍弃
		2. 循环将数组中的数据变为字符串（从 1开始奥）

## 💻 核心代码

```java
// 关键代码片段
public static void main(String[] args) {  
    Scanner scanner = new Scanner(System.in);  
  
    System.out.print("请输入第一个非负整数字符串: ");  
    String num1 = scanner.next();  
  
    System.out.print("请输入第二个非负整数字符串: ");  
    String num2 = scanner.next();  
  
    String result = multiply(num1, num2);  
    System.out.println("它们的乘积为: " + result);  
  
    scanner.close();  
}  
  
/**  
 * 计算两个字符串表示的非负整数的乘积  
 * @param num1 第一个数字字符串  
 * @param num2 第二个数字字符串  
 * @return 乘积的字符串表示  
 */  
public static String multiply(String num1, String num2) {  
    // 边界情况：如果任意一个数为 "0"，乘积直接为 "0"    if (num1.equals("0") || num2.equals("0")) {  
       return "0";  
    }  
    //例子 123 * 123  
    int m = num1.length();  //3  
    int n = num2.length();  //3  
  
    // 两个长度分别为 m 和 n 的数相乘，结果的最大长度为 m + n    int[] res = new int[m + n];   //长度为6 是从 0 到 5  
    // 从右向左遍历两个字符串（即从个位开始相乘）  
    for (int i = m - 1; i >= 0; i--) {  //2  
       int n1 = num1.charAt(i) - '0'; // 获取当前位的数字  
       for (int j = n - 1; j >= 0; j--) {  //2  
          int n2 = num2.charAt(j) - '0'; // 获取当前位的数字  
  
          // 乘积加上之前该位置可能已经存在的值（进位）  
          int sum = n1 * n2 + res[i + j + 1];  
  
          // 当前位保留个位数  
          res[i + j + 1] = sum % 10; //2+2+1=5  
          // 进位加到前一位  
          res[i + j] += sum / 10;   //2+2=4  
       }  
    }  
  
    // 将结果数组转换为字符串，并跳过可能的前导零  
    StringBuilder sb = new StringBuilder();  
    for (int i = 0; i < res.length; i++) {  
       // 如果最高位是 0，则跳过  
       // （因为前面已经排除了 "0" 的情况，所以最多只有一个前导零）  
       // 3位数 * 3位数  
       //最大 999*999 = 998001  6位  
       //最小 100*100 = 10000   5位  
       //也就是 最大 是 m+n 6  最小是m+n-1  5  
       //而此时 去掉前面 两个数中有一个是 0 的情况  
       //所以 只有最高位才有可能 是 0 这一种情况  
       if (i == 0 && res[i] == 0) {  
          continue;  
       }  
       sb.append(res[i]);  
    }  
    return sb.toString();  
}
```

## ⚠️ 易错点 / 注意事项
关于 为什么当前位个位是 i+j+1
### 逻辑推导：
1. **在“现实世界”（从 1 开始数位数）：**
    - `num1` 的最后一位是第 `m` 位。
    - `num2` 的最后一位是第 `n` 位。
    - 它们相乘，结果的最后一位自然是第 `m + n` 位。
    - **差值 = 0** （完美对应，不需要加减）。
2. **在“代码世界”（下标从 0 开始）：**
    - `num1` 的最后一位下标是 `m - 1` （因为从 0 开始，**亏了 1**）。
    - `num2` 的最后一位下标是 `n - 1` （因为从 0 开始，又**亏了 1**）。
    - 它们相加：`(m - 1) + (n - 1) = m + n - 2`。
    - **你看，因为有两个输入字符串，这里一共“亏了 2”！**
3. **目标结果数组（下标也从 0 开始）：**
    - 结果长度是 `m + n`。
    - 它的最后一位下标是 `(m + n) - 1 = m + n - 1`。
    - **这里只“亏了 1”。**
4. **终极对齐（补齐差值）：**
    - 我们手里的下标和是：`m + n - 2`
    - 我们需要达到的目标下标是：`m + n - 1`
    - **差了多少？** `(m + n - 1) - (m + n - 2) = 1`
    - **结论：** 所以必须 ** `+1` ** 来补齐这个差值！

---

### 总结你的神来之笔

你所说的“有了 0，就是 M 和 N 差了 2，而结果 m+n 差了 1，所以+1 就是为了补齐”

假设公式是 `i + j + x`（我们要找出这个 `x` 是多少）： 把最大值代入进去： (m−1)+(n−1)+x=m+n−1(m−1)+(n−1)+x=m+n−1

化简左边： m+n−2+x=m+n−1 m+n−2+x=m+n−1

两边抵消掉 `m + n`： −2+x=−1−2+x=−1 x=1 x=1

### 结论

看！通过你的思路推导出来，**这个 `x` 必须等于 1**。

就像你说的，当 `i=2, j=2` 时，`i+j = 4`。但结果数组的最后一位是 `5`。如果不加 `1`，个位乘个位的结果就会跑到十位上去，整个计算就全错位了。**只有加上 1，才能让最末尾的数字精准对齐到数组的最末尾！**

既然最末尾（`i+j+1`）对齐了，那么前面所有的位（包括进位 `i+j`）自然也就全部对齐了。

所以，你的理解非常透彻：** `i + j + 1` 就是为了弥补“下标从 0 开始”带来的偏移，确保乘法竖式的最右下角能够完美对齐！**
