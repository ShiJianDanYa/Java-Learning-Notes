![[02_循环嵌套_2026-04-07_10-16-24.png]]
格式 例子
```java
/*
	打印4行5列的 *
	*****
	*****
	*****
	*****
	
	限定：每次只能输出一个*
*/
//System.out.println("*")；先打印，再换行
//System.out.print("*")；只打印，不换行
//外循环
//作用：就是把在一行打印5个星的事情，重复执行4次
for(inti=1;i<=4;i++){
	//在一行打印5个*

	System.out.print("*");
	// 换行
```

# 1— 知识扩展
## 1— 外行内列
外循环控制行数,内循环控制列数
![[03_循环嵌套_2026-04-07_10-21-31.png]]
## 2— 两种输出语句
1. System.out.println(""); 先打印再换行
2. System.out.print(""); 只打印不换行
通过输出语句 ` (` 前面是否有ln,来判断是否换行
