## 题目要求
给你一个数组 nums 和一个值 val，你需要删除所有数值等于 val 的元素举例 1:  
输入: nums = [3,2,2,3] val = 3  
输出：nums=[2,2] 剩余 2 个元素举例 1:  
  
输入: nums = [0,1,2,2,3,0,4,2]  val = 2  
输出：nums =[0,1,3,0,4] 剩余 5 个元素
## 思路分析
1. 接受用户输出指定数组的长度
2. 根据输入数组的长度,动态初始化数组
3. 循环和分支判断输入数据元素的合法性
4. 调用去重方法
5. 先创建同长度数组,和变量记录数组删除的数据元素数量
6. 循环判断只有非指定元素才能被添加进新数组
7. 根据变量记录删除的数组元素来创建新数组(与去重后的数量相同)
8. 打印输出新数组

//定义方法 移除数组 中 的指定元素  
//方法需要 提供数组 和 删除的数据元素
public static int[] removeElement(int[] nums, int val) { 
	//先创建同长度的数组newNums 用来接受删除后的数组
    int[] newNums = new int[nums.length];  
    //变量 j 作用 
    //指针 指定下一个数据 在newNums数组中的添加位置
    int j = 0;  
    //记录删除数据的数量  
    int count = 0;  
    //循环遍历数组 
    for (int i = 0; i < nums.length; i++) {
    	//判断 是否和指定元素相同  
        if(nums[i] != val){  
        	//只有不同才会添加到newNums数组
            newNums[j] = nums[i]; 
            //指针加一 
            j++;  
        }else {  
        	//相同的话 删除数据元素数量+1
            count++;  
        }  
    }  
    //创建nums数组 ,长度为 nums-删除的数据元素数量
    nums = new int[nums.length-count];  
    //循环遍历数组 添加newNums元素到nums数组中
    for (int i = 0; i < nums.length; i++) {  
        nums[i] = newNums[i];  
    }  
    return nums;  
}
