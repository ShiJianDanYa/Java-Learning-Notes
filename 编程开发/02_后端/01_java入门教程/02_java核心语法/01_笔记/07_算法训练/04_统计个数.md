## 题目要求
学校选举学生会主席，有 5 个候选人  
全校 1000 名同学参与投票（每人一票，可以弃权，或者选 1-5 号）。  
投票使用 Random 模拟。0：弃权，1~5：给对应的候选人投票  
要求 1:  
统计每个候选人的得票数和得票率，找出得票最多的候选人？  
要求 2:  
统计弃票数和弃票率是多少？
## 思路分析
1. 定义一个数组 长度为 6 存储所有候选人 加 弃权
2. 循环遍历 1000 次  随机范围是 0 到 5 赋值给数组
3. 方法 弃权率 和 得票率  数组中的人数/1000 * 100 后面加上%号
4. 方法 最高得票率 定义变量存储最高数 在通过最高数得到候选人

## 标准解法
在模拟投票中也有一种更简单的解法
```java
for (int i = 0; i < 1000; i++) {  
    int index = random.nextInt(0,6);     
       //index的含义    
       //1. 投票的数据    
       //2. 同样也是数组的索引    
       vote[index]++;  
}
```
