## 题目要求
彩票规则：  
前区：1~35 选 5 个号码（唯一）  
后区：1~12 选 2 个号码（唯一）  
跨区可重复  
  
中奖规则：  
    一等奖：5 + 2    
    二等奖：5 + 1    
    三等奖：5 + 0 / 4 + 2    
    四等奖：4 + 1 / 3 + 2    
    五等奖：4 + 0 / 3 + 1 / 2 + 2    
    六等奖：3 + 0 / 1 + 2 / 2 + 1 / 0 + 2

## 思路分析
1. 先创建数组 
2. 调用 方法分别为两个数组(前 后) 赋值不重复且是指定范围的元素
3. 接受用户输入数据 并进行合法化判断
4. 判断中奖方法
5. 输出中奖结果

## 核心代码
用户输入也好我们随机添加也罢都是需要判断数据是否重复
所以先创建判断是否重复代码
```java
//判断是否有重复  重复输出false 不重复输出true  start~end 指定重复区间 
//方法参数 需要判断是否有重复的数组 是否重复的数字 和在数组中的判断范围  start开头  end结尾 
public static boolean deduplicationMethod(int[] arr ,int a,int start,int end){  
    for(int i = start; i < end; i++){  
       if(arr[i] == a){  
          return false;  
       }  
    }  
    return true;  
}
```
下一步是随机彩票去重方法
```java
//彩票去重方法  
//参数 指定数组 随机数范围(a，b)
public static int[] lotteryTicketDeduplication(int[] arr,int a,int b){  
    Random rd = new Random();  
    int[] newArr = new int[arr.length];  
    //循环遍历添加数组元素(不重复)  
    //定义变量存储添加的元素位置    int i = 0,j = 0;  
    while(i< arr.length){  
       //生成随机数  
        int num = rd.nextInt(a,b);  
        //定义变量判断是否重复  
        boolean flag = true;  
       flag = deduplicationMethod(newArr,num,0,i);  
        if(flag){ //只有不重复  
           //添加i 自加           newArr[i] = num;  
           i++;  
        }  
    }  
  
    return newArr;  
}
```
