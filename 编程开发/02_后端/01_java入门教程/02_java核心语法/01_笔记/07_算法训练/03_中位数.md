## 题目要求
给定两个正序数组 arr 1 和 arr 2，请先合并数组，并找出合并之后数组的中位数。
举例:  
1 2 3 4 5 6 7 8 9  
中位数：5  
1 2 3 4 5 6  
中位数：（3+4）/ 2

## 思路分析
1. 先定义两个数组
2. 开始合并数组
	1. 创建数组 3用来存储两个数组合并,所以长度是 arr 1+arr 2
	2. 创建三个指针变量 
	3. 开始循环遍历数组 条件是 指针大小小于数组长度
	4. 第一种情况 指针 1 大于等于数组 1长度 但是 指针 2 小于数组 2 的长度 这时候直接把 数组 2 的剩余元素添加到 数组 3 中
	5. 第一种情况 指针 2 大于等于数组 2长度 但是 指针 1 小于数组 1 的长度 这时候直接把 数组 1 的剩余元素添加到 数组 3 中
	6. 指针 1 所对应的数据元素 大于 指针 2 所对应的数据元素 ,将指针 2 所对应的数据元素添加到 数组 3 中,让后让双方指针都+1
	7. 指针 2 所对应的数据元素 大于 指针 1 所对应的数据元素 ,将指针 1 所对应的数据元素添加到 数组 3 中,让后让双方指针都+1
	8. 如果指针 1 和指针 2 所对应的数据元素相等,那在数组 1 或数组 2 中任选一个添加到数组 3,三个指针都加+1
3. 求中位数
	1. 先判断是奇数还是偶数 对 2 取模是否等于 0
	2. 是的话(数组长度除于 2+数组长度除于 2-1)除于 2(注意数组的索引和实际相差为 1 为了便于理解 可以为 数组[长度/2+1]+数组[长度/2]  比如数组长度为 10 那就是 6 和 5)
4. 输出数组 3

## 核心代码
第一个合并有序数组
```java
public static int[] merge(int[] arr1,int[] arr2){  
    //创建新数组,用来存储两个数组的数据  
    int[] arr3 = new int[arr1.length+arr2.length];  
    //创建三指针  
    int pointer1 = 0,pointer2 = 0,pointer3 = 0;  
    //循环遍历数组  
    //while循环  是 循环条件为true就继续循环    
    while(pointer1 < arr1.length || pointer2 < arr2.length){  
       //为什么要把 pointer1 >= arr1.length && pointer2< arr2.length
       //写在前面 因为只有 写在前面才不会触发 数组指针 越界 错误
       if(pointer1 >= arr1.length && pointer2< arr2.length) {  
          arr3[pointer3++] = arr2[pointer2++];  
       }else if (pointer2 >= arr2.length && pointer1< arr1.length) {  
          arr3[pointer3++] = arr1[pointer1++];  
       } else if (arr1[pointer1]>arr2[pointer2]){  
          arr3[pointer3++] = arr2[pointer2++];  
       } else if (arr1[pointer1]<arr2[pointer2]) {  
          arr3[pointer3++]= arr1[pointer1++];  
       } else if (arr1[pointer1]==arr2[pointer2]) {  
          arr3[pointer3++]= arr1[pointer1++];  
          pointer2++;  
       }  
    }  
    //返回数组  
    return arr3;  
}
```

```java
//定义方法合并数组  
public static int[] merge(int[] arr1,int[] arr2){  
    //变量存储数组的长度  
    int length1 = arr1.length,  
       length2 = arr2.length,  
       length = length1+length2;  
      
    int[] arr3 = new int[length];  
    //定义指针  
    int index1 = 0,index2 = 0;  
    for (int i = 0; i < length; i++) {  
       //如果数组1已经遍历完  
       if(index1==length1){  
          arr3[i] = arr2[index2];  
          index2++;  
          continue;  
       }  
       //如果数组2已经遍历完  
       if(index2==length2){  
          arr3[i] = arr1[index1];  
          index1++;  
          continue;  
       }  
       //判断数组1和数组2的元素大小  
       if(arr1[index1]<arr2[index2]){  
          //数组1的元素小  
          arr3[i] = arr1[index1];  
          index1++;  
       }else{  
          //数组2的元素小  
          arr3[i] = arr2[index2];  
          index2++;  
       }  
    }  
    //返回数组  
    return arr3;  
}
```
