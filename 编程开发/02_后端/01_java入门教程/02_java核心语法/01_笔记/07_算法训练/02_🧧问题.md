## 题目要求
给你两个整数 M 和 N，M 表示红包的总额，N 表示红包的个数  
现在又 N 个人来抽红包，每个人都是随机的，打印每个人领的红包金额
## 思路解析
1. 首先是用户指定红包的个数和总额
2. 调用随机方法
3. 先是将金额平均分配到个数组中
4. 循环 减去随机范围的金额
5. 再随机范围的人加上减去的金额
## 核心代码
```java
//动态初识化数组 长度是红包人数
int[] arr = new int[n];  
//平均红包金额  
int avg = m/n;  
for (int i = 0; i < n; i++) {  
    arr[i] = avg;  
}  
//开始打乱数据  
//随机数  
Random random = new Random();  
for (int i = 0; i < arr.length; i++) {  
    //随机金额  
    int index = random.nextInt(avg);  
    //随机位置  
    int temp = random.nextInt(n);  
    arr[i] = arr[i] - index;  
    arr[ temp] = arr[temp] + index;  
}
```
