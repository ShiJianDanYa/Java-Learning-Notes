# 题目要求
循环打印 1~100 之间的数字，  
如果数字包含 7  
或者是 7 的倍数，输出"过"

# 思路分析
分析  
7 的倍数 就是对 7 进行取模 结果为 0  
包含 7  
个位是 7 对 十取模 结果为 7  
例子 77  `77 % 10 = 7`
十位是 7 除于 10 结果为 7
例子 77 `77 / 7 = 7`

# 代码演示
```java
public class ch01_逢七过 {  
    public static void main(String[] args){  
     for (int i = 1; i <= 100; i++) {  
          if(i%7==0 || i/10==7 || i%10==7){  
             System.out.println("过");  
             continue;  
          }  
          System.out.println(i);  
       }  
       System.out.println("结束");  
    }  
}
```
