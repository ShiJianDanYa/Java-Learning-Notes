
# 第一题
输出一个梯形

```
|   ***  
|  *****  
| *******
```

外行内列是所以应该是三层循环
第一步 先打印梯形前面的空格
3 2 1
第二步 打印 梯形

| i 的值 | 需要的值 |
| ---- | ---- |
| 1    | 3    |
| 2    | 5    |
| 3    | 7    |
总结 规律
需要值 = 2 * i +1

你是不是觉得
for(int k=3;k<=7;k+=2){  
    System.out.println(" * ");  
}
太天才了
但是结果可能与你想的不一样

| 循环次数 | k 的值 | 结果       |
| ---- | ---- | -------- |
| 1    | 3    | *        |
| 2    | 5    | **       |
| 3    | 7    | ***      |
| 4    | 9    | 大于 7 不成立 |
所以 代码
```java
public class ch03_梯形 {  
  public static void main(String[] args){  
       for (int i = 1; i <= 3; i++) { 
       		// 1 2 3  
            // 空格 3 2 1          
            for(int j=i;j<=3;j++){  
             System.out.print(" ");  
          		}  
          //  1 2 3  
          //* 3 5 7          
          for(int k=1;k<=(2*i+1);k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
    }  
}
```

# 第二题
## 题目要求
打印菱形
```
|    *  
|   ***  
|  *****  
| *******  
|  *****  
|   ***  
|    *
```

## 题目分析 
其实这是一个由三部分构成的图形
1. ▲三角形
2. 最长的由 * 构成的横线
3. 下三角形
但是为了代码方便编写 *  横线可以任意▲结合为一个,大三角形

思路分析
空格部分
3 2 1 0 1 2 3
图形部分
1 3 5 7 5 3 1

### 先打印大▲ 
空格是 3 2 1 0
图形是 1 3 5 7

外行内列
所以是四层循环
for (int i = 1; i <=4; i++) {   
// 1 2 3 4
}
空格
//空格  3 2 1 0  
  
for (int i = 1; i <=4; i++) {
for(int j =i;j<=3;j++){  
    System.out.print(" ");  
}
}
大三角形

| 需要的数据 | 1   | 3   | 5   | 7   |
| ----- | --- | --- | --- | --- |
| i 的值  | 1   | 2   | 3   | 4   |
规律是 (2 * i)-1

### 小三角形
需要三层循环
for (int i = 1; i <= 3; i++) {  
//1 2 3
}
空格
1 2 3
for (int i = 1; i <= 3; i++) {  
    //空格 1 2 3    
    for(int j=1;j<=i;j++){  
       System.out.print(" ");  
    }
 }
小三角形
5  3  1

| i 的 值 | 1   | 2   | 3   |
| ----- | --- | --- | --- |
| 需要的数据 | 5   | 3   | 1   |
规律 7-(2 * i)

## 代码实例
```java
public class ch04_菱形 {  
    public static void main(String[] args){  
       for(int j =i;j<=3;j++){  
             System.out.print(" ");  
          }  
          //大 三角形   1 3 5 7  
          for(int k=1;k<=(2*i-1);k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
  
       //三角形(小)  
       for (int i = 1; i <= 3; i++) {  //1 2 3  
          //空格 1 2 3          for(int j=1;j<=i;j++){  
             System.out.print(" ");  
          }  
          //          1  2  3  
          //小三角形   5  3  1          
          for(int k=1;k<=7-2*i;k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
    }  
}
```

# 第三题
## 题目要求
```java
打印空心菱形
|    *  
|   * *  
|  *   *  
|   * *  
|    *

```

## 题目分析
也是分析为两部分
1. 空心无底大三角
2. 空心无底反小三角
### 空心无底大三角
第一步是三层循环
for (int i = 1; i <= 3; i++) { // 1 2 3
}
```java
| 	 *  
|   * *  
|  *   *  
```

先打印空格  3 2 1
for(int j = 1; j <= 4 - i; j++){  
    System.out.print(" ");  
}
分析
i  1 2 3
第一次  j = 1 4-1 = 3  
第二次  j = 1 4-2 = 2
第三次  j = 1 4-3 = 1

第二步 打印

```java
| 	 *  
|   * 
|  *
```

所以在空格后面接一个 * 即可
System.out.print(" * ");
后面是空格接 * 拼接 
第一行 没有
第二行 一个空格 接 * 号
第三行 两个空格 接 * 号

i = 1 2 3 
k = 0 1 3
规律是 2 * i - 3
注意完成后面会接一个 * 
但是第一层是不需要空格和后面 * 的
所以代码是
if(i > 1){  
    for(int k = 1; k <= 2 * i - 3; k++){  
       System.out.print(" ");  
    }  
    System.out.print("* ");  
}
### 空心无底反小三角

需要打印的符号
```java
|   * *  
|    *
```
