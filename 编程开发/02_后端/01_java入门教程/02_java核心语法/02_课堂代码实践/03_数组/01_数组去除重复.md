# 📝 数组去重
## 📌 题目要求
> 获取10个1-100之间的随机数并存入到数组当中，  
> 要求保证数据是唯一的
> **示例**：
> 输出：
> 9
> 3
> 7
> 5
> 10
> 1
> 8
> 6
> 4
> 2

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：动态初始化生成长度为 10 的数组
2. 第二步：生成符合条件的随机数
3. 第三步：通过循环和布尔类型变量判断是否和数组已有的数据重复
4. 第四步：只有不重复才加入数组中索引加一
5. 第五步: 循环遍历数组

## 💻 核心代码

```java
// 关键代码片段
public static void main(String[] args){  
    //动态初始化  
    int[] arr = new int[10];  
    //随机数生成  
    Random random = new Random();  
  
    for (int i = 0; i < arr.length;) { 
    	//生成随机数 指定范围 1-->10 
        int data = random.nextInt(10)+1;  
        // flag判断是否有重复数据  
        boolean flag = true;  
        //循环遍历 数组数据 是否与添加数据 重复  
        for(int j = 0; j < arr.length; j++)  
        {  
            if(arr[j] == data ){  
                flag = false;  
                //跳出内循环，break语句只能跳出它所在的那一层循环，无法直接跳出多层嵌套循环  
                break;  
  
            }  
        }  
        //只有当没有重复时才会添加  
        if(flag){  
            arr[i] = data;  
            //只有生成一个满足要求的随机数，索引才会自增  
            i++;  
        }   
    }  
    //遍历数组  
}
```

* 如果是获取10个 0 - 100之间的随机数并存入到数组当中,如何区分随机生成 0 和动态初始化默认值 0

for (int i = 0; i < arr.length;) {

        }  
    }
