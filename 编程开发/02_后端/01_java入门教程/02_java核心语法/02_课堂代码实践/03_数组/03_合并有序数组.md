# 📝 
## 📌 题目要求
> 给你两个有序数组arr1和arr2  
> 将两个数组中的数据合并到一个大数组中。要求：合并之后的大数组也是有序的
> **示例**：
> arr1:13579  
> arr2:246810
> 输出：
> arr3:12345678910

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：创建 arr 3 数组 其 长度 是 arr 1+arr 2
2. 第二步：创建三指针 
3. 第三步：循环遍历两个数组结束条件是 数组对应指针大小<数组长度 两个的关系是 &&
4. 第四步：开始判断指针对应的数组元素大小
5. 第五步: 数组 arr 1 所对应的小,那将数组 arr 1 所对应的元素添加到 数组 arr 3 对应指针加一
6. 第六步: 数组 arr 2 所对应的小,那将数组 arr 2 所对应的元素添加到 数组 arr 3 对应指针加一
7. 第七步: 无论是 arr 1 大还是 arr 2 大 最后数组 arr 3 的指针都会加一
8. 第八步:开始处理剩余元素,数组 1 或 数组 2,的长度可能不相等 将还没有处理完数组元素全部 添加到数组 arr 3 中
9. 打印数组 arr 3



## 💻 核心代码

```java
// 关键代码片段
public static void main(String[] args) {  
    int[] arr1 = {1,3,5,7,9};  
    int[] arr2 = {2,4,6,8,10};  
    int[] arr3 = new int[arr1.length + arr2.length];  
    //双指针 对比  
    int i = 0, j =0, k = 0;  
    //循环结束条件是什么  
    while(i<arr1.length && j<arr2.length){  
        if(arr1[i]<arr2[j]){  
            arr3[k] = arr1[i];  
            i++;  
        }else{  
           arr3[k] = arr2[j];  
           j++;  
        }  
        k++;  
    }  
    // 处理 arr1 中剩余的元素  
    while(i < arr1.length){  
        arr3[k] = arr1[i];  
        i++;  
        k++;  
    }  
  
    // 处理 arr2 中剩余的元素  
    while(j < arr2.length){  
        arr3[k] = arr2[j];  
        j++;  
        k++;  
    }  
  
    //输出数组三  
    System.out.println("\n合并后的数组长度为：" + arr3.length); 
    // 应该是 10  
    for (int q = 0; q < arr3.length; q++) {  
        System.out.print(arr3[q] + " ");  
    }  
    }
```
