# 📝 数组中查找指定元素
## 📌 题目要求
> 给定一个递增的有序数组和一个目标值，在数组中找到目标值，打印其索引l。  
> 如果目标值不存在于数组中，打印应插入的位置
> **示例**：
> 数据： nums =[1,3,5,6];    
> 输入：5  
> 输出：2

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：定义数组
2. 第二步：定义整型变量记录位置,布尔类型变量记录是否存在
3. 第三步：接受用户输入 开始循环遍历指定数组
4. 第四步：如果数组元素等于指定元素 布尔变量为 true 
5. 第五步: 如果数组元素小于指定元素,且不等于的换为此变量再加一
6. 第六步: 循环完成 通过布尔 判断数据不存在输出指定位置

## 💻 核心代码

```java
// 关键代码片段
public static void main(String[] args){  
    int[] arr={1,3,5,6};  
    //定义变量记录位置  
    int index=0;  
    //记录是否存在  
    boolean flag = false;  
  
    Scanner scanner=new Scanner(System.in);  
    System.out.println("请输入target的值");  
    int target=scanner.nextInt();  
    //开始循环位置  
    for (int i = 0; i < arr.length; i++) {  
        if(target == arr[i]){  
            flag = true;  
            index = i;  
            System.out.println("i="+index);  
        }  
        if(target != arr[i] && target>arr[i])  
        {  
            index++;  
        }  
    }  
    if(!flag){  
        System.out.println("数据不存在 ,插入位置为："+index);  
    }  
}
```
