# 📝 逢 7 过
## 📌 题目要求
> 循环打印 1~100 之间的数字，  
> 如果数字包含 7  
> 或者是 7 的倍数，输出"过"
> **示例**：
> 输出：
>1,2,3,4,5,6,过,8,9,10,11,12,13,过,15,16,过,18,19,20,过,22,23,24,25,26,过,过,29,30,31,32,33,34,过,36,过,38,39,40,41,过,43,44,45,46,过,48,过,50,51,52,53,54,55,过,过,58,59,60,61,62,过,64,65,66,过,68,69,过,过,过,过,过,过,过,过,过,过,80,81,82,83,过,85,86,过,88,89,90,过,92,93,94,95,96,过,过,99,100,结束

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：循环遍历 1 到 100 判断数字
2. 第二步：7 的倍数 就是对 7 进行取模 结果为 0 
3. 第三步：
   个位是 7 对 十取模 结果为 7  
   例子 77  `77 % 10 = 7`
   十位是 7 除于 10 结果为 7
   例子 77 `77 / 7 = 7`
4. 第四步：符合条件输出过,并且跳过此次循环

## 💻 核心代码

```java
// 关键代码片段
for (int i = 1; i <= 100; i++) {  
         if(i%7==0 || i/10==7 || i%10==7){  
            System.out.println("过");  
            continue;  
         }  
         System.out.println(i);  
      }  
```
