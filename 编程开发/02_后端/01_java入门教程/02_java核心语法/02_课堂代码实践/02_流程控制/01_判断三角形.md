# 📝 判断三角形
## 📌 题目要求
> 键盘录入任意三个大于 0 的小数，
> 判断这三个数值构成什么类型的三角形？ 
> 需要判断的类型如下：  
> 等边、等腰、直角、普通、无效  
> **示例**：
> 输入：
> 请输入三个小数：
> 请输入第一个小数
> 3
> 请输入第二个小数
> 3
> 请输入第三个小数
> 3
> 输出：等边三角形
> 

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：三角形的构成条件：任意两边之和大于第三边 首先判断是否可以构成▲ ,这是一切的前提(构成三角形的条件, `任意` 两边之和大于第三边  `任意` 对应的是 `且`, `只要` 对应的是 `或`, `不要 不能` 对应的是 `取反`)
2. 第二步：等边、等腰、直角、普通他们之间的关系是,(从小到大) `等边 > 等腰 = 直角 > 普通`   注意 等腰和直角不是 像 等边和等腰那样的包含关系 他们是平级的,关键在于一个特殊的三角形(等腰直角) 这样就出现了优先级,如果你把等腰直角划分为直角那等腰就小了,所以直角就比等腰靠前,反之亦然 但是对于计算机来说,判断等腰比直角简单多了,所以如果对等腰直角 不做特殊要求,一般把直角写在等腰前面

## 💻 核心代码

```java
// 关键代码片段
//判断输入  
       if(a>0 && b>0 && c>0){  
       //判断是否可以构成三角形  任意 是 且  
          if(a+b>c && a+c>b && b+c>a){  
             //判断是什么三角形  
             //等边 三边相等             
             if(a==b && b==c) System.out.println("等边三角形");  
             //等腰 有两边相等  
             else if(a==b || b==c || a==c) System.out.println("等腰三角形");  
             //直角 三角形的两边的平方之和等于第三边平方  
             else if(a*a+b*b==c*c || a*a+c*c==b*b || b*b+c*c==a*a) System.out.println("直角三角形");  
             //普通 三角形的两边之和大于第三边  
             else System.out.println("普通三角形");  
          }else System.out.println("输入的能构成三角形?");  
       }else System.out.println("输入的什么玩意");  
       
```
