## 🧠 解题思路分析
**需求拆解 和 解题思路**
![[02_简单解法_2026-05-15_09-03-01.png]]
1. 第一步：先开始打印行数 3层循环
2. 第二步：先开始打印红色三角 在变成空格
3. 第三步：在打印绿色三角
4. 第四步：蓝色正方形
5. 第五步: 天青三角

## 💻 核心代码

```java
// 关键代码片段
for (int i=1 ; i<=3; i++) { // 1 2 3  
          //先打印第一部分 红色 2 1          
          for (int j = i; j <= 2; j++) {  // 2 1 0  
             System.out.print(" ");  
          }  
          //打印第二部分 绿色   1 2 3          
          for (int k = 1; k <= i; k++) {  
             System.out.print("*");  
          }  
          //打印蓝色部分  
          for(int m=1;m<=3;m++){// 3 3 3  
             System.out.print("*");  
          }  
          //打印天青色  
          for(int q =i;q<=2;q++) {//  2 1 0  
             System.out.print("*");  
          }  
  
          System.out.println();  
       }  
```
