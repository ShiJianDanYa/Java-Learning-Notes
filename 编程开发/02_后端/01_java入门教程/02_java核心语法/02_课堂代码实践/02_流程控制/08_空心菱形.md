也是分析为两部分
1. 空心无底大三角
2. 空心无底反小三角

**需求拆解 和 解题思路**
1. 第一步：需要打印的是空心无底大三角 需要三层循环
    ![[11_空心无底大三角_2026-05-15_10-58-41.png]]
    for (int i = 1; i <= 3; i++) {
     // 1 2 3
	}
	1. 先打印空格  3 2 1
	   for(int j = 1; j <= 4 - i; j++){  
		    System.out.print(" ");  
		}
		分析
		i  1 2 3
		第一次  j = 1 4-1 = 3  
		第二次  j = 1 4-2 = 2
		第三次  j = 1 4-3 = 1
	2.  然后后面加上 * 就变成了
	   System.out.print(" * "); ![[12_空心菱形斜_2026-05-15_13-20-59.png]]  
	3. 后面是空格接 * 拼接 
	   第一行 没有
		第二行 一个空格 接 * 号
		第三行 两个空格 接 * 号
		i = 1 2 3 
		k = 0 1 3
		规律是 2 * i - 3
		注意完成后面会接一个 * 
		但是第一层是不需要空格和后面 * 的
		所以代码是
		if(i > 1){  
		   for(int k = 1; k <= 2 * i - 3; k++){  
		         System.out.print(" "); 
		        } 
		         System.out.print("* "); 
		    }
2. 第二步：打印无底反小三角形 需要两层循环
   ![[13_空心无底反小三角_2026-05-15_13-30-55.png]]
   for (int i = 1; i <= 2; i++) {   //1 2  }
	1. 先打印空格 2 3
	   	   for(int j = 1; j <= i + 1; j++){  // 2 3  
		    System.out.print(" ");  
		}
	2. 后面加上 *  
	    System.out.print(" * "); 
	    ![[14_空心无底反小三角斜_2026-05-15_13-40-02.png]]
3. 下面打印  空格 和 * 
   只有第一层有空格 最 底层没有
   所以条件是 i < 2
   i = 1 2
   规律是? 样本太少 推不出来
   把中间添加上来
   循环 3
   for (int i = 0; i <= 2; i++) { //0 1 2
   }
   
   空格 + 星号
   i = 0  1 2
	k = 3 1  0
	规律 
	3 - 2 * i 

## 💻 核心代码

```java
// 关键代码片段
// 上三角（含中间行）  
for (int i = 1; i <= 3; i++) {  
    // 前导空格  
    for(int j = 1; j <= 4 - i; j++){  
       System.out.print(" ");  
    }  
    System.out.print("*");  
    // 中间空格（第1行不打印）  
    if(i > 1){  
       for(int k = 1; k <= 2 * i - 3; k++){  
          System.out.print(" ");  
       }  
       System.out.print("*");  
    }  
    System.out.println();  
}  
// 下三角  
for (int i = 1; i <= 2; i++) {  
    // 前导空格  
    for(int j = 1; j <= i + 1; j++){  
       System.out.print(" ");  
    }  
    System.out.print("*");  
    // 中间空格  
    if(i < 2){  
       for(int k = 1; k <= 3 - 2 * i; k++){  
          System.out.print(" ");  
       }  
       System.out.print("*");  
    }  
    System.out.println();  
}

```
