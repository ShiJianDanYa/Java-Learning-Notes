## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：外行内列是所以应该是三层循环
2. 第二步：先打印梯形前面的空格    3 2 1
3. 第三步：打印 梯形
   
| i 的值 | 需要的值 |
| ---- | ---- |
| 1    | 3    |
| 2    | 5    |
| 3    | 7    |
总结 规律
2 * i +1
## 💻 核心代码

```java
// 关键代码片段
for (int i = 1; i <= 3; i++) { 
       		// 1 2 3  
            // 空格 3 2 1          
            for(int j=i;j<=3;j++){  
             System.out.print(" ");  
          		}  
          //  1 2 3  
          //* 3 5 7          
          for(int k=1;k<=(2*i+1);k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
    }  
```

## ⚠️ 易错点 / 注意事项

* 你是不是觉得  for(int k=3;k<=7;k+=2) 太天才了 但是结果可能与你想的不一样
  外层是循环三次,内层是其实是

| 循环次数 | k 的值 | 结果       |
| ---- | ---- | -------- |
| 1    | 3    | *        |
| 2    | 5    | **       |
| 3    | 7    | ***      |
| 4    | 9    | 大于 7 不成立 |
