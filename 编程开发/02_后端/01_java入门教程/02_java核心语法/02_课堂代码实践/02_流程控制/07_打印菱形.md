# 📝 打印菱形
## 📌 题目要求
> 打印菱形
> **示例**：
> 输出：
> ![[06_菱形_2026-05-15_10-26-09.png]]

## 🧠 解题思路分析
**需求拆解 和 解题思路**
其实这是一个由三部分构成的图形
* ▲三角形
* 最长的由 * 构成的横线
* 下三角形

但是为了代码方便编写 *  横线可以任意▲结合为一个,大三角形
思路分析
空格部分
3 2 1 0 1 2 3
图形部分
1 3 5 7 5 3 1
1. 第一步：第一打印大三角形
	1. 空格是 3 2 1 0    图形是 1 3 5 7
	2. 外行内列 是四层循环 
	    for (int i = 1; i <=4; i++) {   
		// 1 2 3 4
		}
	3. 空格  空格  3 2 1 0 
		for(int j =i;j<=3;j++){  
		    System.out.print(" ");  
		}
	4. 大三角形  规律是 (2 * i)-1 ![[07_菱形_大三角形_2026-05-15_10-40-40.png]]
2. 第二步：小三角形
	1. 需要三层循环
	   for (int i = 1; i <= 3; i++) {  
			//1 2 3
		}
	2. 空格   1 2 3
	   //空格 1 2 3    
		for(int j=1;j<=i;j++){  
	       System.out.print(" ");  
	    }
	3. 小三角形  5  3  1
	   规律 7-(2 * i)![[08_菱形_小三角形_2026-05-15_10-45-27.png]]

## 💻 核心代码

```java
// 关键代码片段
for(int j =i;j<=3;j++){  
             System.out.print(" ");  
          }  
          //大 三角形   1 3 5 7  
          for(int k=1;k<=(2*i-1);k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
  
       //三角形(小)  
       for (int i = 1; i <= 3; i++) {  //1 2 3  
          //空格 1 2 3          for(int j=1;j<=i;j++){  
             System.out.print(" ");  
          }  
          //          1  2  3  
          //小三角形   5  3  1          
          for(int k=1;k<=7-2*i;k++){  
             System.out.print("*");  
          }  
          //换行  
          System.out.println();  
       }  
    }  
```
