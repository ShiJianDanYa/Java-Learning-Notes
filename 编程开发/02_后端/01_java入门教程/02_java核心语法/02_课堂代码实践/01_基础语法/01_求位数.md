# 📝 求位数
## 📌 题目要求
> 求 123 百 十 个 位数
> **示例**：
> 输入：123 
> 输出：
> 1
> 2
> 3

## 🧠 解题思路分析
**需求拆解 和 解题思路**
1. 第一步：接受用户输出数据
2. 第二步：数据除于 100 得到百位数
3. 第三步：数据除于 10在对 10 取模得到 十位数
4. 第四步：数据对 10 取模,得到个位数

## 💻 核心代码

```java
// 关键代码片段
int num = 0;  
        Scanner sc = new Scanner(System.in);  
        System.out.println("请输入一个最高百位整数：");  
        num = sc.nextInt();  
        //假设输入 325  
        //num/100 得到百位数        
        int num1 = num/100;  
        //325/100 = 3  
        //num/10 得到十位数        
        int num2 = num/10%10;  
        //325/10 = 32   32%10 =2  
        //num%10 得到个位数        
        int num3 = num%10;  
        //325%10 = 5  
        System.out.println("百位数为："+num1);  
        System.out.println("十位数为："+num2);  
        System.out.println("个位数为："+num3);  
```
